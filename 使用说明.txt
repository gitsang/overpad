OverPad — 手柄按键悬浮窗
==========================

双击 OverPad.exe 运行。窗口默认出现在屏幕右下角，透明背景，置顶悬浮。
内置两套主题，可在右键菜单里随时切换。


两套主题
--------
HUD 线框（默认）
    细线描边 + 系统字体，暗色极简风格。LT/RT 用横向进度条显示按压深度
    并在旁边标出百分比数字；摇杆中心的品红方块实时反映推杆方向；按下
    按键时描边转白。

像 素 风
    在像素网格上逐格绘制的手柄，按下的键整块变色，辨识度高。


切换与调整（鼠标右键菜单）
--------------------------
主题          HUD 线框 / 像素风
缩放          75% ~ 300%
不透明度      100% / 85% / 70% / 55%
锁定位置      锁定后鼠标可穿透窗口点到底下的游戏
隐藏 / 退出


全局热键（游戏内也可用）
----------------------
  Ctrl + Alt + T      切换主题
  Ctrl + Alt + L      锁定 / 解锁（鼠标穿透）
  Ctrl + Alt + H      隐藏 / 显示
  Ctrl + Alt + ↑      放大
  Ctrl + Alt + ↓      缩小
  Ctrl + Alt + Q      退出

  拖动窗口：鼠标左键按住悬浮窗任意位置直接拖。


关于全屏游戏
------------
Windows 的置顶窗口盖不住「独占全屏」(Exclusive Fullscreen) 的游戏。
如果悬浮窗在游戏里看不见，把游戏的显示模式改成下面任意一种：

  · 无边框窗口 (Borderless Windowed)  ← 推荐，画质帧数基本无损
  · 窗口化 (Windowed)

注意：游戏处于独占全屏时，系统也会屏蔽全局热键。改成无边框窗口后
热键恢复正常。


手柄识别
--------
使用 Windows 自带的 XInput 接口，支持：
  · Xbox One / Xbox Series 手柄
  · Xbox 360 手柄
  · 北通、雷蛇、八位堂等支持 XInput 模式的第三方手柄

没有识别到手柄时，窗口会变成半透明并在中间显示 PRESS ANY BUTTON。
如果一直如此，请检查：
  1. 手柄是否切到了 XInput 模式（很多第三方手柄默认是 DInput，需要按
     组合键切换或拨动手柄背面的模式开关，具体看手柄说明书）
  2. 无线手柄是否已配对并连上
  3. 打开「设置 → 蓝牙和其他设备」确认系统能识别到手柄

不支持 PS4 / PS5 手柄的原生模式（DS4/DualSense），
需要装 DS4Windows 之类的工具把它模拟成 Xbox 手柄。


配置文件
--------
同目录下的 overpad.json，删除后恢复默认设置。
  theme      默认主题：hud / pixel
  zoom       缩放倍数（0.75 ~ 3.0）
  x / y      窗口位置（null 表示自动放到右下角）
  opacity    不透明度 0.0 ~ 1.0
  locked     启动时是否处于锁定（鼠标穿透）状态


说明
----
程序不注入游戏进程，不读写游戏内存，只是一个普通的置顶窗口，
不会触发反作弊。
